# AI Website Copy Generator + AI Evaluator

An intelligent Streamlit application that generates website copy for local businesses and automatically evaluates content quality.

## Features

- Website Copy Generation
- AI Quality Evaluation
- Content Scoring
- Missing Section Detection
- Improvement Suggestions
- Error Handling
- Streamlit Interface

## Tech Stack

- Python
- Streamlit
- OpenRouter
- GPT OSS 20B

## Run

pip install -r requirements.txt

streamlit run app.py
